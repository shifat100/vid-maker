# J2ME в браузере

[English](README.md) · **Русский**

Эмулятор Java ME (MIDP 2.0 / CLDC) на JavaScript. Форк [pluotsorbet](https://github.com/mozilla/pluotsorbet), доработанный под запуск обычных игр и приложений для кнопочных телефонов прямо в браузере, в том числе на смартфоне.

## Возможности

- Высокоуровневый LCDUI (Form, List, TextBox, Alert и т.д.)
- Сокеты и HTTP через WebSocket-прокси на сервере
- Звук: MIDI, WAV, MP3, AMR
- 3D: M3G (JSR-184, движок из J2ME-Loader в WebAssembly) и Mascot Capsule (micro3d)
- Bluetooth (JSR-82): L2CAP и SPP между вкладками и устройствами через комнаты, напрямую по WebRTC или через TURN
- Автоопределение разрешения экрана по манифесту, имени jar и графике
- Экранная клавиатура, поворот, масштаб, настройки для каждой игры
- Платформа выбирается в настройках игры (по умолчанию Sony Ericsson): меняются `microedition.platform` и коды клавиш (софт-клавиши, джойстик, C/Back) под Nokia/SE/Samsung, Siemens, Motorola, LG; есть клавиши C (−8) и Back (−11); на клавиатуре ПК: стрелки, Enter, Q/E — софт-клавиши, Backspace — C, Esc — Back
- Системные свойства (`microedition.locale` и др.) редактируются для каждой игры отдельно: Настройки → «Системные свойства», есть сброс по умолчанию
- Загрузка своих .jar прямо со страницы (хранятся в браузере)
- Файловый менеджер виртуальной памяти телефона (карта памяти, сохранения): загрузка, скачивание, папки

## Быстрый старт

Нужен Python 3.8+, зависимостей нет.

```bash
python3 server.py 8080
```

Открыть http://localhost:8080. Игры можно положить в папку `jar/` (появятся в списке у всех) или добавить кнопкой на странице.

На Windows — `startserver.bat` (разрешает прокси к локальной сети).

## Развёртывание

### VPS (systemd)

```bash
./deploy.sh            # порт 8080
PORT=80 ./deploy.sh    # другой порт
```

Скрипт ставит coturn, создаёт секрет TURN в `/etc/j2me.env`, открывает порты в ufw (если включён) и запускает службу `j2me`. В конце печатает адрес и строки `TURN_URL` / `TURN_SECRET` для других установок.

Порты: сайт (TCP), 3478 (TCP/UDP), 49160–49200 (UDP).

```bash
systemctl status j2me
journalctl -u j2me -f
```

### Docker / Render

`Dockerfile` запускает `start.sh`: если доступен UDP, рядом с сервером поднимается coturn. На Render UDP нет, поэтому TURN там не запускается. Чтобы игроки с Render могли соединяться через TURN, задайте в Environment `TURN_URL` и `TURN_SECRET` от своего VPS. Для Render есть `render.yaml`.

### Переменные окружения

| Переменная | Назначение |
|---|---|
| `PORT` | порт HTTP (по умолчанию 8080) |
| `TURN_URL` | внешний TURN, через запятую: `turn:host:3478,turn:host:3478?transport=tcp` |
| `TURN_SECRET` | общий секрет TURN (`use-auth-secret` в coturn) |
| `TURN_IP` | внешний IP для своего coturn, если автоопределение не подходит |
| `TURN=0` | не запускать свой coturn |
| `ALLOW_PRIVATE=1` | разрешить прокси соединения в локальную сеть |
| `PYTHON` | интерпретатор для `start.sh` |

## Bluetooth-мультиплеер

Когда игра первый раз включает Bluetooth, появляется окно:

- **Создать** — новая комната с названием и паролем, их нужно передать второму игроку. Если комната с таким названием уже есть, создать её нельзя. Способ соединения для всей комнаты: **Авто** (при входе в комнату поднимаются оба канала, напрямую и через TURN, на каждом 20 пингов, выбирается канал с меньшим 90-м перцентилем задержки; если не поднялся ни один — через сервер), **P2P** (напрямую, при неудаче через TURN, сервер не используется), **TURN** (всегда через TURN, сервер не используется, нужен `TURN_URL`);
- **Подключиться** — вход по названию и паролю;
- **Рядом** — без пароля, для игроков с одним внешним IP.

Дальше игра работает как с настоящим Bluetooth: поиск устройств, поиск сервисов, `btl2cap://` и `btspp://`. Сервер только сводит игроков. После соединения данные по возможности идут напрямую (WebRTC), иначе через TURN или WebSocket сервера. Состояние видно по точке на шестерёнке (зелёная — напрямую или через TURN, жёлтая — через сервер, красная — нет связи), подробности — в настройках, раздел «Сетевая игра»: комната, число игроков, способ связи, смена комнаты.

Параметры URL для входа без окна: `?room=имя&pass=пароль&btname=Ник` — подключение к комнате; с `&mode=create` — создание, способ соединения `&net=auto|p2p|turn`. Пустой `?room=` — режим «Рядом».

## Параметры страницы

`main.html?jar=jar/game.jar` и дополнительно:

| Параметр | Значение |
|---|---|
| `screen` | `240x320`, `auto`, `fit` |
| `scale`, `rotate`, `keypad`, `fps`, `jit` | как в настройках (`fps` — ограничение частоты кадров, 0 — без ограничения) |
| `platform` | `se`, `nokia`, `samsung`, `siemens`, `motorola`, `lg` или своя строка |
| `debug=1` | включить отладочный вывод в консоль |

## Сборка Java-части

`java/classes.jar` уже собран. После изменений в `src/`:

```bash
src/bt/build.sh     # JSR-82
src/m3g/build.sh    # M3G (нужен clang с целью wasm32)
```

## Структура

```
bld/        JS-рантайм: VM (j2me.js), MIDP (main-all.js), LCDUI, сеть, звук, 3D, Bluetooth
java/       classes.jar — библиотека классов MIDP/CLDC
src/bt/     исходники JSR-82
src/m3g/    исходники M3G
config/     настройки, локальные jar, параметры URL
server.py   HTTP-сервер, прокси сокетов, сервер комнат Bluetooth
```
